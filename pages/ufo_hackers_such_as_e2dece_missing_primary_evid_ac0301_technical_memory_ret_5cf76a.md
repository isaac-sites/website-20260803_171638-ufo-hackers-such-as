## Introduction

One reason the most extraordinary parts of Gary McKinnon's story remain difficult to evaluate is that they depend almost entirely on memories described years after the alleged events, rather than on preserved digital evidence. This does not mean those memories are false. It does mean they were formed, recalled and discussed over a long period that included repeated interviews, legal proceedings and intense public debate. Research in cognitive psychology shows that repeated recollection can make people increasingly confident in a memory without necessarily making it more accurate.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/33547629/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Answering a factual question today increases one&#x27;s confidence in the same answer tomorrow - independent of fluency - PubMedFebruary...</span></span></span>

Within the broader question of why [missing files]({{ 'missing-files/' | relative_url }}) undermine extraordinary claims, this distinction matters. If original screenshots, documents or contemporaneous notes are absent, later descriptions become the primary evidence. Understanding how memory changes through repeated retelling helps explain why historians, investigators and digital forensic specialists treat confident testimony differently from preserved records.

## Why vivid memories are not complete records

People often assume that highly emotional or unusual experiences are remembered like recordings. Decades of memory research suggests otherwise. Memory is reconstructive: each act of recall rebuilds an event from stored fragments, current knowledge and later experiences rather than replaying an unchanged recording.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/8206816/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Lost but not forgotten details: repeated eyewitness recall leads to reminiscence but not hypermnesia - PubMed...</span></span></span>

Technical observations are especially vulnerable because they usually involve multiple layers of interpretation. A person may later remember:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* what they literally saw on the screen;
* what they inferred the screen meant;
* explanations encountered afterwards; and
* details repeated in later conversations.

</div>

Over time, these elements can become difficult to separate.

Applied to McKinnon's account, there is an important distinction between remembering seeing an unfamiliar spreadsheet title and remembering what that title implied. Likewise, recalling a silvery object in an image is different from recalling precisely what metadata, labels, surrounding windows or file locations accompanied it. Those contextual details would normally help determine whether the material represented operational data, a simulation, image processing work or something else entirely. Without preserved files, later memory must carry the entire evidential burden.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.wired.com/2006/06/ufo-hacker-tells-what-he-found/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wired.com">[WIRED]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wired.com</span><span class="citation-popover-title">ufo hacker tells what he found</span><span class="citation-popover-snippet">WIRED&#x27;UFO Hacker&#x27; Tells What He Found &#124; WIREDJune 21, 2006...</span><span class="citation-popover-meta">Published: June 21, 2006</span></span></span>

## How repetition affects confidence

Repeated recall changes memory in several ways that are relevant to historical claims.

First, every retelling strengthens the accessibility of the narrative itself. People become quicker at recalling the same sequence of events, which can create a stronger subjective feeling that the memory is reliable.

Second, confidence and accuracy do not always move together. Experimental work has repeatedly shown that answering the same questions multiple times can increase confidence even when factual accuracy does not improve. Participants often become more certain simply because the same response has been retrieved before.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/33547629/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Answering a factual question today increases one&#x27;s confidence in the same answer tomorrow - independent of fluency - PubMedFebruary...</span></span></span>

Third, repeated interviews tend to stabilise a coherent narrative. This does not necessarily mean new false memories are created. Rather, uncertain details may gradually become omitted, simplified or expressed with greater certainty than they originally deserved. Researchers studying eyewitness testimony have found that successive recalls can produce both new remembered details and forgotten ones, while overall confidence can remain high.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/8206816/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Lost but not forgotten details: repeated eyewitness recall leads to reminiscence but not hypermnesia - PubMed...</span></span></span>

The important point is that consistency across later interviews is not, by itself, proof that every remembered detail was present in the original experience.

## McKinnon's public narrative developed over years

McKinnon's alleged intrusions occurred during 2001–2002. His most widely quoted descriptions, however, became familiar to the public through interviews given several years later, while he was engaged in a lengthy extradition dispute.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.wired.com/2006/06/ufo-hacker-tells-what-he-found/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wired.com">[WIRED]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wired.com</span><span class="citation-popover-title">ufo hacker tells what he found</span><span class="citation-popover-snippet">WIRED&#x27;UFO Hacker&#x27; Tells What He Found &#124; WIREDJune 21, 2006...</span><span class="citation-popover-meta">Published: June 21, 2006</span></span></span>

During this period he repeatedly discussed subjects such as:

* the partially downloaded [NASA image]({{ 'nasa-image/' | relative_url }});

<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the "Non-Terrestrial Officers" spreadsheet;
* his motivations for searching government systems; and
* his interpretation of what he believed he had found.

</div>

Repeated interviews naturally reinforced these episodes as the central elements of his public story. At the same time, the absence of preserved digital artefacts meant there was no independent reference against which evolving descriptions could be checked.

An often-overlooked point is that McKinnon himself occasionally expressed uncertainty about interpretation. In the 2006 *Wired* interview, for example, he acknowledged that the spreadsheet might conceivably have related to a military game or similar activity rather than representing what he initially suspected. That qualification illustrates an important distinction between remembering seeing a document and knowing what it meant.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.wired.com/2006/06/ufo-hacker-tells-what-he-found/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wired.com">[WIRED]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wired.com</span><span class="citation-popover-title">ufo hacker tells what he found</span><span class="citation-popover-snippet">WIRED&#x27;UFO Hacker&#x27; Tells What He Found &#124; WIREDJune 21, 2006...</span><span class="citation-popover-meta">Published: June 21, 2006</span></span></span>

## What early notes could have preserved

Contemporaneous documentation often protects investigators against normal memory change.

Had detailed notes existed from immediately after the alleged viewing, they might have recorded information such as:


<div class="content-enhancement content-enhancement--phrase-pills" markdown="1">

* exact filenames;
* directory paths;
* application names;
* timestamps;
* neighbouring files;
* wording copied directly from the screen;
* uncertainty about individual observations.

</div>

These records would have captured what McKinnon believed he saw before years of interviews, legal argument and public discussion could influence how the episode was mentally organised.

Equally valuable would have been explicit statements of uncertainty. A note reading "possibly said X" or "could not read final column" is often more informative than a later confident reconstruction, because it preserves the witness's original level of certainty rather than a polished retrospective account.

## Why this matters when evaluating extraordinary technical claims

Memory research does not imply that McKinnon's descriptions are fabricated, nor does it prove they are accurate. Instead, it explains why investigators distinguish between sincere testimony and independently verifiable evidence.

When original files no longer exist, repeated retelling can produce a narrative that feels internally consistent and is delivered with genuine confidence. That confidence may reflect the stability of the remembered story rather than the completeness of the original observation. Experimental evidence consistently shows that confidence can increase independently of accuracy, making subjective certainty an unreliable substitute for preserved evidence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/33547629/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[PubMed]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Answering a factual question today increases one&#x27;s confidence in the same answer tomorrow - independent of fluency - PubMedFebruary...</span></span></span>

For this reason, the missing screenshots, files, metadata and contemporaneous notes remain central to evaluating McKinnon's UFO-related claims. Without them, later recollections—however honestly given—cannot be tested against the original technical context that might have confirmed, clarified or contradicted what was remembered.

    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>
