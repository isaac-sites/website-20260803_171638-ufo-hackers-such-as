## Introduction

Claims that unusual objects were removed from government imagery cannot be evaluated simply by looking at a single published picture. The crucial question is whether an apparently unusual feature disappeared because of ordinary scientific image processing, or because someone deliberately altered the content. Without both the original source image and the processed version, there is no reliable way to distinguish between those possibilities.



<img src="{{ "/assets/images/ufo_hackers_such_as_e2dece_missing_primary_evid_ac0301_original_altered_ima_9a6622-Illustration-1-dark.svg" | relative_url }}" alt="Image Pairs illustration 1" data-theme-src-dark="{{ "/assets/images/ufo_hackers_such_as_e2dece_missing_primary_evid_ac0301_original_altered_ima_9a6622-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/ufo_hackers_such_as_e2dece_missing_primary_evid_ac0301_original_altered_ima_9a6622-Illustration-1-light.svg" | relative_url }}" loading="eager" decoding="sync" fetchpriority="high">

Within discussions surrounding Gary McKinnon's reported observations of NASA imagery, this distinction is especially important. McKinnon did not preserve the image he described, leaving no before-and-after pair available for independent examination. As a result, neither supporters nor sceptics can test claims that an object was removed, obscured, cropped or otherwise changed. Instead, the discussion remains dependent on recollection rather than verifiable digital evidence.

* the original image as acquired from the imaging system;
* the processed version released or distributed afterwards; and
* evidence showing that one was derived directly from the other.

Only then can investigators identify exactly what changed.

This principle is routine in scientific imaging. NASA missions typically preserve original scientific image data alongside calibrated or enhanced products created for analysis or public release. Processing may include correcting detector artefacts, adjusting brightness, assembling mosaics or applying colour information, while preserving the underlying scientific record. NASA's documentation explicitly distinguishes between raw archival data and processed images created for scientific interpretation or public presentation. Raw products retain original resolution, bit depth and extensive metadata, whereas processed products are intended to improve usability without inventing new features.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/solar-system/multimedia/raw-images-faq/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science Raw Images FAQ</span><span class="citation-popover-snippet">NASA ScienceRaw Images FAQ - NASA ScienceNovember 2, 2024...</span><span class="citation-popover-meta">Published: November 2, 2024</span></span></span>

If both versions existed for the image McKinnon described, investigators could ask straightforward questions:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Did every feature remain present?
* Was any object removed?
* Was the image merely cropped?
* Were contrast or brightness adjustments responsible for making a feature appear or disappear?
* Were any edits fully documented as part of normal processing?

</div>

Without both files, none of these questions can be answered conclusively.

## Routine Processing Versus Deliberate Removal

A common misunderstanding is that any difference between two versions of an image automatically implies censorship. In practice, scientific image processing routinely changes how an image looks without changing what was actually recorded.

Typical legitimate processing includes:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* calibration to remove detector noise or instrument artefacts;
* correction for lens distortion or sensor defects;
* combining multiple exposures;
* colour balancing or false-colour rendering;
* contrast enhancement to reveal faint detail;
* cropping for publication layout or presentation.

</div>

NASA's published guidance explains that such processing is standard scientific practice and serves to improve interpretation of data rather than insert or remove genuine objects. Scientists generally retain access to higher-quality archival data while producing processed images for different analytical or communication purposes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/solar-system/multimedia/raw-images-faq/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science Raw Images FAQ</span><span class="citation-popover-snippet">NASA ScienceRaw Images FAQ - NASA ScienceNovember 2, 2024...</span><span class="citation-popover-meta">Published: November 2, 2024</span></span></span>

By contrast, deliberate removal of an object would usually leave a different pattern of evidence. Depending on the editing method, investigators might expect inconsistencies between [image versions]({{ 'image-versions/' | relative_url }}), unexplained missing pixels, altered metadata, undocumented processing steps or discrepancies between archived and published files.

That distinction is precisely why both image versions matter. A processed image alone cannot reveal whether a missing feature reflects legitimate calibration or intentional alteration.

## How Hashes and Metadata Protect the Comparison

Even possessing two visually similar images is insufficient unless their authenticity can be established.

Digital forensic practice relies on several complementary safeguards.

**Cryptographic hashes.** A secure hash functions as a digital fingerprint. If even one pixel changes, the resulting hash changes. Matching hashes demonstrate that a file has remained unchanged since it was preserved, while differing hashes confirm that some modification occurred, although not what the modification was.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://nvlpubs.nist.gov/nistpubs/ir/2022/NIST.IR.8387.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nvlpubs.nist.gov">[NIST Publications]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nvlpubs.nist.gov</span><span class="citation-popover-title">Publications NIST Interagency Report</span><span class="citation-popover-snippet">NIST PublicationsNIST Interagency ReportMay 8, 2026...</span><span class="citation-popover-meta">Published: May 8, 2026</span></span></span>

**Metadata.** Scientific image files typically contain far more than visible pixels. Metadata may record acquisition time, exposure settings, instrument identification, calibration history, processing level, software versions and observational geometry. These records help determine whether a processed image was produced through a documented scientific workflow or an undocumented editing process.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/solar-system/multimedia/raw-images-faq/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science Raw Images FAQ</span><span class="citation-popover-snippet">NASA ScienceRaw Images FAQ - NASA ScienceNovember 2, 2024...</span><span class="citation-popover-meta">Published: November 2, 2024</span></span></span>

**Documented processing history.** A transparent workflow allows investigators to trace how one version became another. Modern scientific archives often preserve raw data while generating calibrated products through repeatable processing pipelines, allowing later researchers to reproduce results independently.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ntrs.nasa.gov/citations/20090041677" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ntrs.nasa.gov">[NASA Technical Reports Server]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ntrs.nasa.gov</span><span class="citation-popover-snippet">NASA Technical Reports ServerProcessing Raw HST Data With Up-to-Date Calibration Data - NASA Technical Reports Server (NTRS)...</span></span></span>

Together, hashes, metadata and documented provenance transform an image comparison from a visual impression into a testable forensic exercise.

## Why the Evidence Gap Matters

The absence of preserved image pairs is significant because it prevents both confirmation and refutation of removal claims.

If only a processed image survives, it is impossible to determine whether:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* nothing unusual ever appeared in the original;
* an unusual feature resulted from imaging artefacts that were correctly removed;
* later processing legitimately changed the appearance of the scene; or
* content was intentionally removed.

</div>

Likewise, if only an original image survives without documentation of subsequent processing, later published versions cannot be evaluated against an authenticated baseline.

In McKinnon's case, no publicly authenticated original image corresponding to his account has been preserved alongside a documented processed version. Consequently, there is no evidential basis for conducting the kind of before-and-after forensic comparison that would be required to evaluate claims that unusual objects were removed from government imagery. The missing image pair does not support the removal claim, nor does it disprove it; it leaves the central allegation untestable using accepted methods of digital evidence analysis.
