## Introduction

NASA’s independent study of unidentified anomalous phenomena (UAP) concluded that one of the biggest weaknesses in many UFO photographs and videos is not necessarily the image itself, but the absence of the information that should accompany it. A dramatic picture may appear compelling, yet without the original file, timestamps, camera settings, sensor characteristics and processing history, investigators often cannot determine what the image actually shows. NASA identified missing sensor metadata as a major reason why many reported UAP cases cannot support reliable scientific conclusions, even when photographs or videos exist.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report-0.pdf?emrc=67322e8f26f79" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">uap independent study team final report 0</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA...</span></span></span>

This matters not only for current UAP investigations but also when assessing older claims connected with alleged government secrets or stories involving figures such as Gary McKinnon. Regardless of how striking an image may appear, scientific evaluation depends on whether its origin and technical context can be independently verified rather than on the visual content alone.

## Which metadata investigators need

An image file contains much more than visible pixels. Modern cameras, smartphones and scientific instruments typically record technical information that helps reconstruct how an image was created. When preserved, this metadata allows analysts to evaluate whether an apparent anomaly is consistent with an aircraft, astronomical object, atmospheric effect, camera artefact or something genuinely unexplained.

For UAP investigations, particularly valuable metadata includes:

## How editing and compression alter interpretation

Even when a UFO photograph is authentic in the sense that it depicts a real scene, editing can remove or distort valuable evidence.

Many common actions affect evidential quality:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Social media platforms often recompress uploaded images and videos.
* Messaging applications may resize photographs automatically.
* Cropping removes surrounding context that could identify landmarks or lighting conditions.
* Contrast enhancement, sharpening or noise reduction can introduce visual artefacts.
* Exporting to another format may discard embedded metadata entirely.

</div>

These changes are often routine rather than deceptive. Someone may simply upload an image to make sharing easier. However, once the original file has been replaced by a compressed copy, investigators lose information needed to distinguish between camera artefacts and genuine objects.

Compression can also create misleading effects. Bright objects against dark skies frequently develop halos, blocky edges or motion artefacts after repeated JPEG or video compression. Without access to the original recording, analysts cannot easily determine whether unusual shapes originate from the scene itself or from the compression process.

Digital image forensics research similarly shows that metadata contributes important clues when reconstructing an image's provenance—the sequence of creation, editing and redistribution that brought it to its current form. Combining metadata with pixel analysis generally provides stronger evidence than analysing the visible image alone.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://arxiv.org/abs/1807.03376" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: arxiv.org">[arXiv]</a><span class="citation-popover" role="note"><span class="citation-popover-source">arxiv.org</span><span class="citation-popover-title">arXiv Beyond Pixels: Image Provenance Analysis Leveraging Metadata</span><span class="citation-popover-snippet">Beyond Pixels: Image Provenance Analysis Leveraging MetadataJuly 9, 2018...</span><span class="citation-popover-meta">Published: July 9, 2018</span></span></span>

## Why screenshots cannot replace original files

A recurring problem in UFO discussions is reliance on screenshots instead of original photographs or videos.

Screenshots preserve only what appears on the display at one moment. They usually discard:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* Original EXIF camera information.
* Embedded timestamps.
* Camera orientation data.<span class="citation-chip-wrap"><a class="citation-chip" href="https://science.nasa.gov/solar-system/multimedia/raw-images-faq/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[science.nasa.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">raw images faq</span><span class="citation-popover-snippet">raw images faq</span></span></span>
* GPS coordinates where available.
* Original colour information.
* Sensor-specific calibration details.
* Cryptographic provenance information when present.

</div>

Consequently, a screenshot is often unsuitable for detailed forensic examination, even if the original image once contained useful technical evidence.

The problem has become more significant as newer provenance technologies have emerged. Standards such as Content Credentials (C2PA) allow compatible systems to embed signed information about an image's origin and editing history. However, taking a screenshot commonly strips this provenance information away, making later verification impossible. Even organisations deploying such standards note that screenshots routinely remove embedded provenance metadata.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://c2pa.org/specifications/specifications/2.2/explainer/Explainer.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: c2pa.org">[C2PA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">c2pa.org</span><span class="citation-popover-title">and Content Credentials Explainer:: C2PA Specifications</span><span class="citation-popover-snippet">C2PA and Content Credentials Explainer:: C2PA Specifications...</span></span></span>

For historical UFO images, where only scanned prints, photocopies or screenshots survive, this limitation means investigators often cannot establish whether an unusual appearance originated during capture, subsequent editing or repeated copying.

## Why missing metadata limits scientific conclusions

Missing metadata affects almost every major question investigators hope to answer.

Without accurate timestamps, analysts may be unable to compare observations with:


<div class="content-enhancement content-enhancement--phrase-pills" markdown="1">

* Commercial and military flight records.
* Satellite passes.
* Astronomical objects.
* Meteor activity.
* Weather radar.
* Atmospheric conditions.

</div>

Without camera specifications, estimating an object's true size or distance becomes extremely uncertain. A bright point recorded with a long telephoto lens may represent something entirely different from an identical-looking point captured using a wide-angle smartphone camera.

Likewise, missing information about exposure time prevents reliable calculations of apparent motion. An elongated light streak could indicate a fast-moving object, camera shake during a long exposure, or a stationary light photographed while the observer moved.

NASA therefore emphasised that scientific confidence comes not from dramatic imagery but from combining multiple calibrated observations with complete contextual information. Images alone rarely provide sufficient evidence when separated from the data describing how they were produced.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report-0.pdf?emrc=67322e8f26f79" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">uap independent study team final report 0</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA...</span></span></span>

## The lesson for evaluating UFO evidence

NASA's assessment shifts attention away from asking whether a photograph "looks convincing" and towards asking whether it can be independently examined.

An image gains evidential strength when investigators can verify:

* The original, unmodified file.
* Complete metadata.
* A documented [chain of custody]({{ 'chain-of-custody/' | relative_url }}).

<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Known camera characteristics.
* Independent observations from additional sensors or witnesses.
* Reproducible analytical methods.

</div>

Conversely, an image loses much of its scientific value when only a compressed copy, screenshot or edited version survives. This does not prove the image is false, nor does it prove the reported object was ordinary. Instead, it means the available evidence is too incomplete to support confident conclusions.

That principle forms a central part of NASA's broader approach to UAP research. The agency's report argues that better evidence will come not from collecting more striking photographs, but from preserving complete datasets in which the image and its accompanying metadata remain together, allowing independent investigators to reconstruct the circumstances of the observation and test competing explanations objectively.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nasa.gov/wp-content/uploads/2023/09/uap-independent-study-team-final-report-0.pdf?emrc=67322e8f26f79" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nasa.gov">[NASA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nasa.gov</span><span class="citation-popover-title">uap independent study team final report 0</span><span class="citation-popover-snippet">UNIDENTIFIED ANOMALOUS PHENOMENA...</span></span></span>

    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
