## Introduction

Gary McKinnon's account of seeing an unusual spacecraft-like object depends almost entirely on what he recalls viewing over a slow remote connection rather than on an original image that can be examined today. That distinction matters because remote desktop technology, low-bandwidth connections and reduced display settings can all change how an image appears without changing the underlying file itself. None of these limitations proves that McKinnon misidentified what he saw, but they do mean that his visual impression cannot be treated as equivalent to examining a preserved, full-resolution image. Within the broader problem of missing primary evidence, the quality of the viewing conditions becomes another reason to be cautious when evaluating extraordinary claims.

## What reduced colour depth can hide

McKinnon stated that he viewed the image over a 56 Kbps dial-up connection and deliberately reduced the remote display to 4-bit colour and a low screen resolution so that the picture would appear more quickly.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://boingboing.net/2006/06/21/interview-with-ufo-h.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: boingboing.net">[Boing Boing]</a><span class="citation-popover" role="note"><span class="citation-popover-source">boingboing.net</span><span class="citation-popover-title">Boing Boing Interview with &quot;UFO Hacker&quot; Gary Mc Kinnon: why&#x27;d he do it?</span><span class="citation-popover-snippet">Boing BoingInterview with &quot;UFO Hacker&quot; Gary McKinnon: why&#x27;d he do it? - Boing BoingJune 21, 2006...</span><span class="citation-popover-meta">Published: June 21, 2006</span></span></span>

A 4-bit display is capable of showing only 16 colours at any one time. Compared with true-colour displays, this forces many subtle tones into the same limited palette. As a result:

* Gradual shading can become abrupt blocks of colour.
* Small differences between materials may disappear.
* Thin features may merge into the background.
* [Reflections]({{ 'reflections/' | relative_url }}) and highlights can appear unnaturally smooth or sharply defined.

Modern remote desktop software still allows administrators to reduce colour depth over constrained links because transmitting fewer colours requires less data, although the trade-off is reduced image fidelity. Citrix documentation, for example, notes that lowering colour depth improves responsiveness on slow networks at the expense of image quality.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://docs.citrix.com/en-us/citrix-virtual-apps-desktops/2511/policies/reference/ica-policy-settings/visual-display-policy-settings" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: docs.citrix.com">[Citrix Documentation]</a><span class="citation-popover" role="note"><span class="citation-popover-source">docs.citrix.com</span><span class="citation-popover-title">Documentation Visual display policy settings &#124; Reference</span><span class="citation-popover-snippet">Citrix DocumentationVisual display policy settings &#124; ReferenceApril 27, 2026...</span><span class="citation-popover-meta">Published: April 27, 2026</span></span></span>

If the original [NASA image]({{ 'nasa-image/' | relative_url }}) contained subtle textures, atmospheric haze, labels or fine structural details, a heavily reduced palette could have removed exactly the information needed to distinguish an ordinary object from something unusual.

## How partial loading creates visual artefacts

The slow connection introduces a second source of uncertainty. McKinnon said he was remotely controlling the NASA desktop while the large image was loading over his dial-up connection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://boingboing.net/2006/06/21/interview-with-ufo-h.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: boingboing.net">[Boing Boing]</a><span class="citation-popover" role="note"><span class="citation-popover-source">boingboing.net</span><span class="citation-popover-title">Boing Boing Interview with &quot;UFO Hacker&quot; Gary Mc Kinnon: why&#x27;d he do it?</span><span class="citation-popover-snippet">Boing BoingInterview with &quot;UFO Hacker&quot; Gary McKinnon: why&#x27;d he do it? - Boing BoingJune 21, 2006...</span><span class="citation-popover-meta">Published: June 21, 2006</span></span></span>

Remote desktop systems do not generally transmit an original image file directly to the viewer. Instead, they send compressed updates representing what appears on the remote screen. Under restricted bandwidth they prioritise responsiveness by reducing image quality, delaying updates or progressively refining the display as additional data arrives.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://learn.microsoft.com/en-us/azure/virtual-desktop/rdp-bandwidth" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: learn.microsoft.com">[Microsoft Learn]</a><span class="citation-popover" role="note"><span class="citation-popover-source">learn.microsoft.com</span><span class="citation-popover-title">Learn Remote Desktop Protocol bandwidth requirements Azure Virtual Desktop</span><span class="citation-popover-snippet">Microsoft LearnRemote Desktop Protocol bandwidth requirements Azure Virtual Desktop - Azure &#124; Microsoft Learn...</span></span></span>

That process can produce temporary effects such as:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Blocky regions before finer detail appears.
* Smoothed edges that later become irregular.
* Missing portions of the screen awaiting refresh.
* Compression artefacts around high-contrast features.
* Reduced sharpness while the display progressively improves.

</div>

These temporary distortions are familiar to anyone who has used remote desktop software over a slow connection. They are normally corrected as additional data arrives, but McKinnon has said the session ended before he could preserve the image. If his observation was made during an intermediate rendering stage, there is no surviving record showing how the fully rendered picture eventually appeared.

This does not mean the object itself was an artefact. Rather, it means that the visual conditions under which it was interpreted were less reliable than examining the original image directly.

## Why missing scale and captions matter

Even a technically perfect image can be misunderstood if presented without context. NASA guidance on interpreting imagery stresses the importance of scale, orientation, colour interpretation and surrounding information before drawing conclusions from visual features.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/earth/earth-observatory/how-to-interpret-a-satellite-image/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science How to Interpret a Satellite Image: Five Tips and Strategies</span><span class="citation-popover-snippet">NASA ScienceHow to Interpret a Satellite Image: Five Tips and Strategies - NASA ScienceNovember 18, 2013...</span><span class="citation-popover-meta">Published: November 18, 2013</span></span></span>

Because no screenshot survives, several contextual elements remain unknown:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* whether the image contained measurement scales;
* whether captions identified the subject;
* whether adjacent windows explained the file;
* whether the apparent object occupied only a tiny part of a much larger scene;
* whether overlays, annotations or interface elements were hidden by the limited display.

</div>

These missing contextual cues are especially important because human observers naturally interpret unfamiliar shapes using prior expectations. A smooth metallic-looking form viewed without scale, metadata or surrounding information is inherently more ambiguous than the same image accompanied by explanatory labels.

## Viewing conditions increase uncertainty rather than resolve it

McKinnon's description has remained broadly consistent over the years, but consistency of recollection is not the same as independent verification. The technical circumstances he described—56 Kbps dial-up, remote desktop viewing, reduced colour depth, lowered resolution and an interrupted session—represent conditions under which visual information was intentionally sacrificed to make remote viewing possible.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://boingboing.net/2006/06/21/interview-with-ufo-h.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: boingboing.net">[Boing Boing]</a><span class="citation-popover" role="note"><span class="citation-popover-source">boingboing.net</span><span class="citation-popover-title">Boing Boing Interview with &quot;UFO Hacker&quot; Gary Mc Kinnon: why&#x27;d he do it?</span><span class="citation-popover-snippet">Boing BoingInterview with &quot;UFO Hacker&quot; Gary McKinnon: why&#x27;d he do it? - Boing BoingJune 21, 2006...</span><span class="citation-popover-meta">Published: June 21, 2006</span></span></span>

Taken together, these limitations do not demonstrate that the image was ordinary, fabricated or misremembered. Equally, they prevent the observation from serving as strong visual evidence for an extraordinary claim. Without the original file, an uncompressed screenshot or associated metadata, there is no way to determine whether the apparent spacecraft appearance reflected the underlying image, temporary display artefacts, missing contextual information or some combination of all three.

For that reason, the quality of the remote viewing environment strengthens the broader conclusion reached elsewhere in discussions of McKinnon's claims: the absence of the original files does not merely leave questions unanswered—it makes it impossible to separate the image itself from the limitations of the way it was seen.

    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
